# diffusionNN — text-to-network diffusion model

## Context

Repository vuoto: progetto greenfield per un modello di **diffusion text→rete neurale**, analogo a un text2image ma con "immagine" = tensor dei pesi. Coppie di training ("rete neurale", "testo") generate sinteticamente: addestriamo migliaia di piccoli controller MLP su task di tipo game/animation e associamo a ciascuno una caption inglese. Il modello finale genera nuovi modelli da prompt testuale.

Scelte confermate: caption solo inglese, encoder testuale MiniLM congelato (`all-MiniLM-L6-v2`, 384-dim, scaricato da HuggingFace), famiglia canonica unica di reti, tutto in inglese (codice+doc). Ambiente: PyTorch 2.7.1 **CPU-only** — tutto dimensionato per CPU con config smoke veloce + config full.

## Design chiave

**Rete canonica ("dimensioni definite")**: MLP `8 → 32 (tanh) → 32 (tanh) → 8 (linear)` = 1.608 parametri. Ogni task usa i primi k input e m output; il resto è azzerato. Identica per tutti i task ⇒ canvas dei pesi a forma fissa.

**Canvas dei pesi ("immagine")**: 6 canali 32×32 — `W1`(pad 32×8→32×32), `W2`(32×32), `W3`(pad 8×32), `b1`, `b2`, `b3`(pad). Più 6 canali di **maschera statica** (1 dove c'è un peso reale) concatenati come conditioning della UNet. Normalizzazione z-score per-tensore calcolata sul corpus, clamp ±4, scala a [-1,1]. Round-trip encode/decode testato.

**Corpus sintetico** — 6 task differentiabili (dinamiche in torch, rollout 120 step):
- `seek`: raggiungere un target in movimento (steering, gioco)
- `evade`: sfuggire un persecutore (gioco)
- `balance`: cart-pole (gameplay fisico)
- `bounce`: intercettare una palla rimbalzante con un paddle (pong-like)
- `gait`: oscillatore di andatura, match di traiettorie periodiche (animation)
- `orbit`: mantenere orbita circolare (animation/space)

Per task: training **vettorizzato a batch** (64 reti in parallelo, parametri `(B,out,in)`, Adam attraverso le dinamiche) con variazione di seed/init/lr ⇒ reti diverse ma competenti; filtro qualità su rollout discreto. Target ~4.800 reti (~600-800/task) + val split 10%. Costo stimato CPU: 30-90 min.
**Caption**: 4-6 template inglesi per task con slot (input/output/qualità/comportamento) → diversità linguistica; embedding MiniLM precalcolati e cachati con i pesi (safetensors + jsonl).

**Diffusion**: UNet compatta (~2M param, base ch 48-64, livelli 32→16→8, attention+**cross-attention ai token di testo** a 16×16 e 8×8, time-embedding FiLM). Cosine schedule T=1000, **v-prediction**, loss mascherata sui pesi validi, **CFG** (dropout condizione 10%, guidance 3-5), campionamento **DDIM** 50 step, EMA. Input UNet: 12ch (6 rumore + 6 maschera), output 6ch.

**"Modello che genera modelli"**: `generate.py --prompt "..." --task seek` → prompt → DDIM → canvas → pesi → MLP canonico → rollout nel task → report score + GIF comportamento + heatmap pesi + safetensors della rete generata. `eval.py`: success rate su caption di validation (seed mai visti) vs baseline (pesi random, rete mediana del corpus).

## Milestones (ognuna verificata prima della successiva)

1. **Scaffolding + controller + canvas**: `config.py`, `controller.py` (forward, batched, encode/decode canvas, maschera, normalizzazione), test round-trip. *Verifica: `pytest tests/test_canvas.py`.*
2. **Task + corpus**: 6 ambienti differentiabili con `score/render`, `train_controllers.py` batched, template caption, store safetensors+jsonl, download encoder + cache embedding. *Verifica: mini-corpus (20/task) generato, score sopra soglia, `pytest tests/test_tasks.py test_corpus.py`.*
3. **Diffusion**: schedule cosine, UNet con cross-attn, loss v-pred + CFG dropout, DDIM sampler. *Verifica: test shapes, determinismo DDIM, overfit smoke su 50 campioni (loss → ~0) — `tests/test_diffusion.py`.*
4. **Training**: `train_diffusion.py` (EMA, checkpoint/resume, val loss, log). *Verifica: run smoke (~1.5k step, ~20-30 min CPU) con val loss in discesa.*
5. **Generazione + eval**: `generate.py` (prompt→rete→rollout→GIF/heatmap/report), `eval.py` (tabella success rate). *Verifica: prompt "steers toward a moving target" produce rete con score ≥ soglia su `seek`; `eval.py` produce tabella.*
6. **Full corpus + full training**: corpus completo (~4.800 reti, 30-90 min) + training `small`/`base` (stima 3-6h / overnight CPU), eval finale + README.

Fallback: se il download MiniLM fallisse, la classe encoder espone la stessa interfaccia per un encoder piccolo addestrabile (solo pianificato, non implementato di default).
